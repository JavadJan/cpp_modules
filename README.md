# C++ Learning Modules (cpp00-cpp09)

Progressive C++ coursework covering fundamentals to advanced topics.

## Module Overview

| Module | Topics | Exercises |
|--------|--------|-----------|
| **cpp00** | I/O, strings, basic syntax | 3 |
| **cpp01** | Memory, pointers, constructors, destructors | 7 |
| **cpp02** | Fixed-point arithmetic, operator overloading | 4 |
| **cpp03** | Inheritance, class hierarchy | 3 |
| **cpp04** | Polymorphism, virtual functions, abstract classes | 3 |
| **cpp05** | Exception handling, custom exceptions | 4 |
| **cpp06** | Type casting, conversion operators | 3 |
| **cpp07** | Templates, generic programming | 3 |
| **cpp08** | STL containers and algorithms | 3 |
| **cpp09** | Real-world application (Bitcoin exchange) | 3 |

## Quick Start

Navigate to any module and exercise:
```bash
cd cpp0X/exYY
make
./program_name
```

Each exercise builds on previous concepts, progressing from basic I/O to advanced OOP and generic programming.
